## 4. 待办（按影响面 ÷ 成本排序）

1. ~~**H2 + L1**（`src/components/AiAsk.astro` 提交未去重、SSE reader 未释放）~~ ——
   **已解决**（2026-10-16）：提交改为「同一问题重复提交直接忽略、换问题则 `abort` 上一次」，
   `signal` 贯穿两条问答链路并在被取消后不再改动界面（避免旧响应污染新输出）；
   `readStream` 在 `finally` 中 `releaseLock()`。新增 e2e 用例覆盖请求次数与输出归属。
2. ~~**H1**（同文件，`document` 级监听器随客户端路由累积）~~ —— **已解决**（2026-10-16）：
   监听器改挂 `AbortController` 的 `signal`，并在 `astro:after-swap` 时统一解绑、同时中止
   在途请求。当前未启用 `ClientRouter`，暂无触发条件，属预防性修复。
3. ~~**H3**（同文件，`bestWindow` 上界越界产生短窗口）~~ —— **已解决**（2026-10-16）：
   起点上界改为 `text.length - size`，并补一个末尾对齐的窗口，避免短窗口被评为最佳
   与结尾证据被漏掉。
4. ~~**L4**（Worker `checkJs: false`，`src/index.js` 无任何类型检查）~~ —— **已解决**（2026-10-16）：
   `checkJs + strict + @cloudflare/workers-types`（版本按 compatibility_date 选 `5.20260915.1`），
   补 JSDoc 标注与手写 `src/env.d.ts`（Env 与 wrangler.toml 对应），新增 `pnpm check:worker`
   并纳入 `typecheck.yml`。检查立刻抓出两处真问题：`env.SITE_URL` 未在配置中声明（N4，已补）、
   以及模型返回结构的 `any` 逃逸（U3，已收敛到 `readModelText`）。
   另新增 `pnpm test:worker`：不起网络、桩化 AI 绑定直接调 `fetch` 的 10 项最小用例，
   覆盖 M2/M3/M4 与 U3 —— 这是后续 M5/M10/M11/M12 的验证底座。
5. ~~**M5 / M10 / M11 / M12**（Worker 与前端异常处理）~~ —— **已解决**（2026-10-16）：
   - **M5**：删除永不执行的流式分支与 `toAnswerStream`（`stream: false` 是刻意的，
     该模型流式下会吞数字），响应固定为单事件 SSE；
   - **M10**：`normalize` 改为「剥离 → 解码 → 再剥离」—— 顺序不可反，先解码会让
     `&lt;script&gt;` 变成真标签从而绕过剥离；命名实体与数字实体都解码，未知实体原样保留，
     双重编码仍按字面（已知边界）。用例直接在桩里断言**真正送进模型的消息**；
   - **M11**：前端 `parseEvents` 遇到无法解析的 SSE 行时首次打一条 `console.warn`，
     不再静默吞掉上游格式变化；
   - **M12**：生成失败分级 —— 3036（当日额度用尽，重试无效）→ 429；3040（瞬时容量不足）
     → 503 + `Retry-After: 10`；其余 → 502。错误码取自
     `adr/2026-09-14-AI-Search-容量限流调优.md` 的实测表；前端据此区分提示，
     新增 `aiAsk.quota` 文案（zh-CN / en / ja / zh-TW 四份同步）。
6. ~~**M6 / M7 / M9**（重复实现）~~ —— **已解决**（2026-10-16）：
   - **M6 / M7**：新增 `shared/plain-text.js`（HTML → 纯文本）与 `shared/markdown-text.js`
     （Markdown → 标题纯文本），四处消费方改为同一来源：loader 的标题推导、remark 插件的
     「H1 与页面标题是否重复」判定、浏览器端问答召回、Worker 的 prompt 组装。
     两处原有分歧随之消除：① 标题推导只剥行内 Markdown，内联 HTML 与实体（`<kbd>`、`&amp;`）
     会留在**页面标题**里；② 前端的 HTML 剥离不解码实体，与 Worker 对同一段 Pagefind 文本
     给出不同结果。顺带修掉标题规则吞转义字符的老问题（`左 \* 与 \* 右` 曾被误判为强调）。
     之所以用 `.js` 而不是 `.ts`：Worker 的最小用例由 `node` 直接运行（不转译），而
     `node`、Vite、wrangler 都能导入 `.js`；类型由 JSDoc 提供并由 `pnpm check:worker`
     的 `--checkJs --strict` 强制执行。
   - **M9**：`scripts/content_rules.py` 收敛 Python 侧的豁免清单 —— 原先 `check-content.py`
     的 `SKIP_FRONTMATTER_CHECK` 与 `normalize-titles.py` 的 `SKIP_FILES` 各存一份、取值相同
     却无约束。

   `scripts/cloudflare-env.sh` 作单一来源。
