## 七、注意事项

### Git 历史体积

上述大文件已进入提交历史（最早可见于「迁移hexo框架到docsify」提交）。仅在工作区删除文件不会减小仓库体积，历史对象仍会被克隆。

如需真正瘦身，需重写历史，例如：

```bash
git filter-repo --path <文件路径> --invert-paths
```

该操作会改写提交哈希，需协调所有协作者重新克隆，建议在执行前备份。

### 跨端构建关联

本站正在进行跨端改造（参见 `2026-09-09-跨端方案调研.md`），小程序端构建脚本须显式排除二进制文件，当前 `docs/` 中的约 94 MB 二进制资源不应进入小程序包。
